# Translation credits

The Russian, Chinese, Korean and French dictionaries in this directory were
imported from the **hafen-client** by EnderWiggin —
<https://github.com/EnderWiggin/hafen-client> — which pioneered translation
support for Haven & Hearth clients. The bulk of that data is item names,
action names and item descriptions, which are the same for every client
talking to the same server.

The bundle format Apricot uses (per-category JSON files, keys by English text
or by resource path, `@n`/`$n` capture-group substitution, and the
missing-string dump) follows that client's design so translations can move
between the two.

Corrections and additions made since the import are Apricot's own.

Polish and German are stubs waiting for translators; see
`Translations/README.md` for how to fill them in.
